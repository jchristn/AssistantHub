TesseraCloud Environment Configuration: Development (dev)

Document ID: eng-tesseracloud-config-dev. Owner: Platform Engineering. Last updated: 14 July 2025. This page describes the development environment only. Staging and production use different hosts, ports and settings; see their own configuration pages.

Environment summary

  • Environment name (TC_ENV): dev
  • Region: euw1 only, no disaster-recovery replica.
  • Forge environment: tesseracloud-dev. Every merge to a feature branch with the label deploy-dev is deployed automatically.
  • Data: synthetic telemetry only. Copying customer data into dev is prohibited by the Data Classification Standard.
  • Access: all TesseraCloud engineers; no just-in-time elevation required.

Deployment

Deployments to dev need no approval and may happen at any time. The dev environment is reset every Sunday at 03:00 UK time, which truncates all telemetry tables and reloads the synthetic data set.
